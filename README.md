Лабораторная работа №3: асинхронный JavaScript и REST API.

## Описание

Веб-приложение «Доска публикаций»:
- загружает 5 публикаций с JSONPlaceholder (GET);
- создаёт новую публикацию (POST) с валидацией формы;
- показывает состояния загрузки, успеха и ошибок;
- обрабатывает сетевые сбои и HTTP-ошибки (404 и т.п.).

## Технологии

- HTML5
- CSS3
- Чистый JavaScript (без фреймворков)
- Fetch API, async/await
- JSONPlaceholder (тестовый REST API)

## Запуск локально

1. Распакуйте архив.
2. Откройте index.html в браузере (двойной клик).
3. Либо запустите локальный сервер:
   python -m http.server 8000
   и откройте http://localhost:8000.
4. Нужен доступ в интернет — запросы идут к jsonplaceholder.typicode.com.

## Результаты проверки

- «Загрузить публикации» → появляются 5 записей с заголовком и текстом.
- Пустые поля / одни пробелы → появляется ошибка, запрос НЕ отправляется.
- Корректные заголовок и текст → успешный ответ (HTTP 201),
  выводится ID и заголовок, публикация добавляется на страницу.
- Подмена URL GET на .../postz → появляется сообщение об ошибке
  (HTTP 404), кнопка снова активна для повторной попытки.

## Примечание

JSONPlaceholder имитирует создание публикаций — новые записи
не сохраняются на сервере постоянно. Это ожидаемое поведение по заданию.
